# Notas de modelo e limites

O catálogo usa números atômicos e nomes em português constantes no material fornecido. O campo de massa é uma referência inteira aproximada e não identifica um isótopo estável universal para cada elemento. O desenho atômico é expressamente didático e não deve ser interpretado como modelo físico ou químico quantitativo.

As identidades por microcubo são identificadores visuais do software, não alegações de que cada cubo físico tenha propriedades materiais equivalentes ao elemento representado. A identidade permanece associada ao slot do enxame para permitir rastreabilidade visual durante as transformações.
